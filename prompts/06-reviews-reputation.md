# Prompt 6: Review & Reputation System

## Overview
Progressive trust system with mandatory reviews and reputation building.

## Requirements

### Review Submission
- Rating (1-5) + optional comment
- Blockchain record for integrity
- Immutable after submission

### Progressive Rules
**New Providers** (< 3 reviews):
- Max 1 active project
- Reviews block new acceptances

**Established** (≥ 3 reviews):
- Unlimited concurrent projects
- Reviews required but non-blocking

### Reputation Metrics
- Average rating
- Total reviews
- Completion rate
- Recent activity weight
