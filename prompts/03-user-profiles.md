# Prompt 3: Provider Profile System

## Overview
Build comprehensive user profiles for artists including portfolios and media management.

## Requirements

### Profile Data
- Display name, biography
- Profile and header images  
- Portfolio gallery
- Skills and social links
- Statistics (projects, rating, earnings)

### Media Upload
- Secure pre-signed URL flow
- MIME type validation
- Image optimization
- Content moderation
- NudeNet scanning with admin notification (going to be used elsewhere)

### API Endpoints
- Create/update profile
- Add/remove portfolio items
- Public profile view
